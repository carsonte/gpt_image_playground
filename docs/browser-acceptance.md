# 浏览器级验收记录

更新时间：2026-08-29

本记录用于发布前在本机 Google Chrome 中重复验收。测试只使用本地 Vite、应用服务器和 mock 上游，不上传用户图片或生产密钥。

## 启动方式

在项目根目录分别启动以下服务：

```bash
node scripts/mock-image-api.mjs
npm run server
npm run dev
```

托管版本地验收使用与 `scripts/dev-full.mjs` 相同的 Vite 环境变量，将 API 代理指向本地应用服务器；mock 上游监听 `127.0.0.1:8787`，应用服务器监听 `127.0.0.1:8788`，Vite 监听 `127.0.0.1:5173`。端口被占用时可使用等价的空闲端口，并同步修改代理地址。

## 结果摘要

- 首页与 `/admin` 均可独立加载；入口采用路径动态导入和轻量 `Suspense` 占位。
- 本地 mock 已覆盖一次生成、一次编辑、上游错误和请求 ID 展示。
- 验收过程中未读取、上传或持久化用户图片，未在浏览器中填写生产密钥。

## 后续复测建议

每次发布前先运行 `npm run verify:release`，再按上表顺序复测首页、编辑、错误请求 ID 和 `/admin`。如需核对网络阶段诊断，在后台“日志中心”按请求 ID 查看线路、阶段耗时、请求/响应字节数和回退次数。
